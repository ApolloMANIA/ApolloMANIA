# 💫 About Me:
I'm a 4th-year Computer Science student and a full-stack developer who likes turning messy ideas into clean, working products. <br>
I build across the stack — React and modern frontend on one side, Node/Express or Java APIs on the other — and I'm comfortable wiring up databases, auth, and cloud deploy flows when something needs to ship.<br><br>
Outside class, I'm usually shipping side projects, experimenting with cloud/devops tooling, and sharpening system design skills so I can move from "it works on my machine" to "it works in production." <br>
I'm always down to collaborate, learn something new, and build things that feel fast, useful, and a little over-engineered on purpose 😄<br>
